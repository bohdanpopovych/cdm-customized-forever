# Changelog

## 0.1.0

First release.

- Custom width, height and zoom for the Essential, Utility and Buff Icon bars, set in Edit Mode. Icons are cropped, never stretched.
- Add any spell or item to the Essential and Utility bars, before or after the native icons.
- "Additional cooldowns left" and "Additional cooldowns right" groups with full layout options, movable in Edit Mode.
- CDM Customizer tab in the Cooldown Manager window (`/cdm`, `/cdmc`) with drag and drop, an Add box, and a spellbook / inventory browser.
- Cooldown swipe, charges, reagent cast counts, item counts, usability tint and range indicator on every custom icon.
- `/cdmc` commands: status, list, add, remove, reset, copyfrom, debug.
